Quick start

Running in two commands.

Needs WordPress 6.5+, PHP 8.1+ and MySQL or MariaDB. Web Push needs HTTPS and PHP’s OpenSSL extension.

  1. 1

    Get the plugin

    {% highlight bash %} cd wp-content/plugins git clone https://github.com/worldoptimizer/flurfunk.git flurfunk {% endhighlight %}

    Or upload a release zip under Plugins → Add New → Upload Plugin.

  2. 2

    Activate it

    {% highlight bash %} wp plugin activate flurfunk {% endhighlight %}

    Activation creates the tables and a #general channel for the team.

  3. 3

    Set it up

    Settings → Flurfunk: name, logo, colours, who counts as team or guest, and the channels. Then open Flurfunk in the admin menu.
