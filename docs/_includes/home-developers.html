For developers

Plain PHP and JavaScript. Hooks everywhere.

No build step and no framework. Register a slash command with cards, attach threads to your own objects, embed threads on any admin screen, or post from scripts and CI through the REST API.

  • flurfunk_register_target() attaches threads to products, customers or anything else.
  • Flurfunk.mountRefs(), mountChannel() and mountTarget() embed threads on admin screens.
  • Assistant accounts post through WP-CLI or the REST API, with no editing rights.
  • wp flurfunk export and import move everything, files included.
