FAQ

Questions people ask first.

Is it free?

Yes. Flurfunk is free software under the GPL-2.0-or-later. The source is on GitHub.

Does it need an external service?

No. Flurfunk keeps everything in its own tables in your WordPress database and needs no external service, library or API key. Mail goes through wp_mail(). Web Push is encrypted by the plugin itself and sent directly to the browsers’ push services, which needs HTTPS and PHP’s OpenSSL extension. Only the optional AI assistants talk to an AI provider – the one you choose.

What can the AI assistants do, and what not?

They are a module, off by default, for WordPress 7.0 or newer; the provider and its key are the ones set up under Settings → Connectors. Per assistant you choose what it may do: read posts and look things up, suggest tasks, write drafts, propose changes to posts as a card with before and after. It works with the rights of the person asking, never more, and never administers the site; it never publishes, and every change to an existing post needs a person to apply it. What it reads is sent to the provider, so mention it in your privacy policy. AI assistants for admins

Does it work with OpenStation?

Yes. When the OpenStation plugin is active, Flurfunk adds a desktop icon and OpenStation’s dock shows the same unread badge as the menu item. Without OpenStation it works just the same in plain wp-admin. The flurfunk_openstation_icon filter moves or removes the icon.

Can guests see internal threads?

Not unless a channel allows it. Every channel has one level for the team and one for guests: all, own-posts or none. An internal channel is set to none for guests. In an own-posts channel each guest only sees the threads about their own posts, and the team sees a hint on threads guests can read.

What about privacy?

The data stays in your database. Flurfunk takes part in WordPress’s Export Personal Data and Erase Personal Data tools: erasing replaces a person’s messages with a note and removes their read state, mentions, task assignments, notifications, push subscriptions and preferences, so conversations stay readable for everyone else. When a user is deleted, their personal data is removed as well. Privacy in detail

Can I move it to another site?

Yes. wp flurfunk export bundle/ --files writes everything, files included, in the flurfunk/1 format; wp flurfunk import bundle/ reads it on the other site. Moving a site
